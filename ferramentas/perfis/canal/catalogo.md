# Catálogo — perfil "canal"

Padrões que funcionam para vídeos de dinheiro/YouTube. Repertório, nunca obrigação.

- Painel de analytics com contador de visualizações disparando (ícone de olho)
- Faixa de valores "R$ x — R$ y" com trilho que preenche entre os dois extremos
- Barras comparativas crescendo com atraso escalonado (evolução 1K → 10K → 100K)
- Gráfico de linha desenhando com ponto brilhante na ponta e preenchimento em degradê
- Contador acelerado com explosão de "+K" saindo do número
- Revelação: escurece → slot "R$ ????" girando → slam do valor + moedas 3D + flash + tremida
- Cadeado → cadeado aberto ("monetizado") com explosão verde
- Selo/carimbo "✕" sobre uma ideia errada ("valor fixo", "tarifa especial")
- Tela dividida "A vs B" com indicadores ilustrativos ($ vs $$$) e selo "comparação ilustrativa"
- Nó central com cartões ligados por linhas que pulsam (fatores que influenciam)
- CTA: interface de comentários, cursor em arco clicando no botão, balões de comentário empilhando
